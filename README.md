# 거대한 침묵의 궤적: 아인자츠그루펜(Einsatzgruppen)과 악의 평범성 (1941–1943)

> **"악은 결코 악마적인 악인에게서만 나오지 않는다. 그것은 사유를 멈춘 평범한 관료와 지식인들의 침묵 속에서 가장 참혹하게 시스템화된다."** — 한나 아렌트

---

## 📌 프로젝트 개요 (Overview)
본 프로젝트는 제2차 세계대전 독소전쟁 초기(1941~1943년), 나치 독일 제국보안본부(RSHA) 소속 이동 살인 부대인 **아인자츠그루펜(Einsatzgruppen)**의 동유럽 전선 침략 및 집단학살 궤적을 디지털 카토그래피로 재구성하고, 철학자 한나 아렌트의 **『악의 평범성(The Banality of Evil)』** 개념을 통해 현대 조직과 개인의 윤리적 책임을 성찰하는 **100% 독립형 단일 페이지 인터랙티브 웹 역사 아카이브**입니다.

---

## 🛡️ 핵심 기술 사양 (Key Tech Specifications)

- **프레임워크**: React (TypeScript) + Vite
- **스타일링**: Tailwind CSS + Lucide React 아이콘
- **100% 독립형 오프라인 지도 엔진 (No External Dependencies)**:
  * 외부 지도 SDK(Mapbox, Google Maps, Leaflet 등)나 유료/무료 타일 서버, API 키를 **일절 사용하지 않는 완전한 자체 인라인 SVG 엔진**
  * 폐쇄망 및 오프라인 환경에서도 동유럽 전선, 수계망, 국경선, 작전선, 학살 핀이 즉각 렌더링
- **고도화된 인터랙션 줌·팬 (Zoom & Pan Interaction)**:
  * 마우스 휠 스크롤 줌인·줌아웃 (마우스 포인터 중심축 고정)
  * 노트북 터치패드 핀치 제스처 (확대/축소) 지원
  * 터치스크린 멀티터치(2-finger pinch) 및 마우스 휠 클릭(가운데 버튼) 드래그 지원
- **듀얼 테마 시스템 (High-Contrast Theme System)**:
  * **다크 모드**: 흑요석 심연 배경(`#0b0d11`) + 흑백 군사 작전도 + 핏빛 레드(`#dc2626`) 악센트
  * **라이트 모드**: 전시기록 양피지 인쇄본(`#f8f6f1`) + 고대비 차콜 잉크 톤

## 🗺️ 역사 사료 및 카토그래피 고증 (Historical Datasets)

### 1. 아인자츠그루펜 4대 집단군 진격선 (Operational Routes)
- **Group A (발트 3국·레닌그라드 축선, Amber `#f59e0b`)**: 동프로이센 $\rightarrow$ 카우나스 $\rightarrow$ 빌뉴스 $\rightarrow$ 리가 $\rightarrow$ 탈린 $\rightarrow$ 레닌그라드
- **Group B (벨라루스·스몰렌스크·모스크바 중앙선, Cyan `#06b6d4`)**: 바르샤바 $\rightarrow$ 비아위스토크 $\rightarrow$ 민스크 $\rightarrow$ 모길료프 $\rightarrow$ 스몰렌스크 $\rightarrow$ 모스크바 접근선
- **Group C (우크라이나 중북부·키이우·하르키우, Rose `#f43f5e`)**: 상레지아 $\rightarrow$ 르비우 $\rightarrow$ 지토미르 $\rightarrow$ 키이우 $\rightarrow$ 폴타바 $\rightarrow$ 하르키우
- **Group D (남부 우크라이나·크림·카프카스, Purple `#c084fc`)**: 루마니아 $\rightarrow$ 키시너우 $\rightarrow$ 미콜라이우 $\rightarrow$ 심페로폴 $\rightarrow$ 세바스토폴 $\rightarrow$ 크라스노다르

### 2. 7대 집단학살 거점 사료 (Major Massacre Sites)
- **바비 야르 (Babi Yar, 키이우)**: 1941.09.29–30 | 희생자 33,771명 | 존더코만도 4a (대협곡 총살)
- **포나리 숲 (Ponary, 빌뉴스)**: 1941.07–1943.11 | 희생자 약 100,000명 | 아인자츠코만도 9/3 (유류 저장 구덩이 학살)
- **룸불라 숲 (Rumbula, 리가)**: 1941.11.30–12.08 | 희생자 약 25,000명 | 프리드리히 예켈른 ('정어리 통조림' 식 매장)
- **카미야네츠-포딜스키**: 1941.08.27–28 | 희생자 23,600명 | 헝가리 추방 난민 대상 집단 총살
- **심페로폴 (크림 반도)**: 1941.12.09–13 | 희생자 약 14,000명 | 오토 올렌도르프 (대전차 참호 학살)
- **드로비츠키 야르 (하르키우)**: 1941.12–1942.01 | 희생자 약 16,000명 | 혹한기 밀폐 가스차(Gas Van) 집중 투입
- **오데사 대학살**: 1941.10.22–24 | 희생자 약 34,000명 | 군용 창고 감금 방화 및 난사
*각 거점 클릭 시 독일 제국보안본부(RSHA) 기밀 작전 보고서(*Ereignismeldungen UdSSR*) 원문 및 국문 번역 열람 가능.*

### 3. 10단계 시계열 컨트롤러 & 실시간 계측기
- 1941년 6월 바르바로사 작전 개시부터 1943년 12월 1005 작전(증거 인멸)까지 10단계 순차 진행
- 2.5초 자동 재생/일시정지 및 누적 추정 희생자 실시간 카운팅

### 4. 최종 사법 결말 모달 (Nuremberg Trial & Aktion 1005)
- **피해 대비 가해 규모 비교**: 가해 부대 불과 3,000여 명 대비 150만~200만 명 학살
- **1005 작전 (Aktion 1005)**: 파울 블로벨 주도하에 암매장 시신을 파내어 소각하고 뼈를 분쇄한 국가 범죄 은폐의 전모
- **뉘른베르크 재판 (Case 9)**: 수석 검사 벤저민 페렌츠의 기소 및 오토 올렌도르프의 궤변, 전후 사법적 한계 조명

### 5. 한나 아렌트의 '악의 평범성' 심층 에디토리얼
- 관료제적 기계화와 언어 규칙(*Sprachregelung*) 분석
- 타인의 관점에서 생각하기의 무능(*Thoughtlessness*) 비판
- 지휘관 24명 중 8명이 명문대 박사 학위자였던 지식인의 도덕적 파탄 실증
- 현대 조직 생활을 점검하는 3가지 윤리적 성찰 질문 및 저널
